## 数值性质与权重变化

记旧的未归一化机体系视线为 `g=(u,v,h)=s f`，`s=||g||`。
旧矩阵是 `D_old=[−h,0,u; 0,−h,v]`，其两个奇异值为 `s,|h|`。
当 `h=0` 时秩降为1，接近零时法方程的相关权重衰减为 `h²`。

新矩阵满足 `DDᵀ=I₂`、`DᵀD=I₃−ffᵀ`，所以任意三维向量 `w` 均有

`||Dw||² = wᵀ(I−ffᵀ)w = ||w×f||²`。

旧目标只包含 `w×g` 的前两个分量，新目标包含单位视线叉积的完整模平方。
对单位视线，两个横向残差方向的权重从 `1,h²` 变成 `1,1`；对于非单位齐次输入，
还去掉了输入模长带来的尺度权重。线约束未变，因此点/线之间的相对权重也可能改变。
这与已有点候选评分使用单位视线叉积的形式一致，但不等价于最优像素噪声加权，
也没有让原本有限的候选搜索和细化成为精确的全局残差优化器。

10,423 个方向的测试结果：

| 检查 | 最大误差/范围 |
| --- | ---: |
| `||QᵀQ−I||_F` | 4.97e-16 |
| `||Qᵀf||` | 1.17e-16 |
| `||DᵀD−(I−ffᵀ)||_F` | 5.67e-16 |
| 残差平方恒等式误差 / `max(1,||w||²)` | 7.34e-16 |
| 新矩阵全部奇异值 | [0.9999999999999996, 1.0000000000000004] |

所有方向新矩阵秩均为2；旧矩阵在 `h=0`、`1e-16` 时数值秩为1，
`h=1e-12/1e-8` 时最小奇异值约为 `1e-12/1e-8`，新矩阵对应值均约为1。
另已直接验证正、负齐次缩放下的投影矩阵不变性和非零相机中心的零残差。
